# OffBoard upright reorientation leaf

`Skeleton::UpdateRootTransformsOffBoard` at `0x82b448e8` calls `XMVectorSinCos` at `0x82b4493c`, builds its yaw basis, and calls `Skeleton::ReorientSkaterUpright` at `0x82b449a4` only when the passed reorientation flag is set. The call is before the function's animation-to-world matrix assertions at `0x82b449b0` onward. This file covers only that child call; the remaining root update is still a typed boundary.

IDA `ReorientSkaterUpright` at `0x82b3b668` forms `cross(animationToWorld.yAxis, worldUp)` using the YZXW (`0x63`) VMX permutation and tests its dot3 squared length strictly greater than `Math::VECFLOAT_SMALL`, `0x37800000`, at `0x82b3b6e4`. A false, equal, or unordered comparison returns without writing. It next forms `cross(animationToWorld.yAxis, animationToWorld.zAxis)` and applies the same strict test at `0x82b3b738`; that failure also returns without writing. On success it applies one reciprocal-square-root estimate with two refinement steps to the second cross, constructs the candidate axes `[normalizedCross, worldUp, cross(normalizedCross, worldUp)]`, and copies the original full translation. At `0x82b3b7f4` it invokes the existing `PhysicsUtility::InterpolateMatrix44Affine` with the old animation-to-world matrix, candidate, and literal blend `0x3dcccccd` (`0.1f`), then stores all four returned columns at `0x82b3b804..820`.

The isolated Rust leaf `skeleton_offboard_reorient.rs` reuses `cross_full4`, `refine_drive_reciprocal_sqrt`, and `try_interpolate_affine_typed`; it keeps unknown W lanes typed. It returns `None` for either no-write gate and `Some(matrix)` only after interpolation completes. The interpolation's host reciprocal/trig and exceptional-FPSCR behavior remain its documented numeric boundary. The leaf is not yet registered or called by the live skeleton update; the caller must retain native SinCos-before-reorient order and publish only `Some` into the existing `SkeletonRootTransforms.animation_to_world` owner.
