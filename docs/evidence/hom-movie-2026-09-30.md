# Hall of Meat authored scoring movie

Source: January 17 2009 reference build `data/fe/screens.big`, member
`data\fe\source\screens\hud2\homscoring.{apt,const,geo,rx2}`.
Read-only extraction used `tools/extract_big.py`; ActionScript/timelines were
decoded with `tools/inspect_apt.py --scripts`. Extracted assets remain scratch
files and are not redistributed. APT FNV-1a is **65f4830a**. Movie index 3.
Stage 1280 by 720, 16 ms frame period, 60 characters, no imported characters,
no positive clip-depth masks, no clip events. All geometry, texture references,
fonts, positions, colors and tween keyframes come from the original movie.
Bitmap texture IDs are 1,2,3,4,7,8,9,10,20,24,26,28,30,32,37,39,41,43,45,47,54;
every ID has a matching `homscoring_textures\<id>.Texture` in the movie RX2.
Exhaustive placement inspection found only shape, text and sprite characters;
none of these bitmap characters is placed directly on any timeline.
Fonts are Marker_streak and HelveticaPresto, already bound by original Vault
font references. No custom control or imported placeholder needs replacing.

## Action coverage

- Root constructor 0x5ce0 and class InitAction (character 59) 0x5de4 are
  translated by `HomMovie`. Constructor stops root, places `mScore` at
  `endanim`, calls Show(false), resets bonus metrics. Screen_EdgeOffset is
  zero in the current 1280-wide HUD setup.
- All timeline actions except the following are the exact Stop/End pair
  already implemented by retained clips.
- Character 19 action 0x6cb8 calls AnimStarted. Action 0x6cfc calls
  AnimFinished and stops. Those callbacks gate the 22-frame score animation.
- SetState body 0x6068 accepts 1 Show, 2 Hide, 3 UpdateScoring, 999 challenge
  background/audio, 1000 normal background. Show starts the original intro
  (frame 1 through 52); Hide immediately sets visibility false, starts outro
  and resets rows/stickers. It does not invent a delayed hide.
- Root intro finishes with mScore at (43,466); original nested placements
  position the title, Thrasher graphic and total score underneath that.
- UpdateScoring 0x6118 formats total score, conditionally starts mScore's
  animation, updates metrics and collision popups. Score-scroll audio follows
  the original integer conversion of the previous grouped string.
- UpdateBonusScoring 0x6368 allocates five rows in first-activation order.
  Thresholds actually referenced by this shipped script are [1,1,5,1,1].
  Drop references speed threshold; rotation references duration threshold,
  despite unused fields for drop/rotation. First activation intentionally
  leaves scoreText at its authored value until the next update. Rotation's
  statText is empty. Reset clears statText but does not clear scoreText.
- CreateBonusCollisionPopup 0x69c8 selects White/Black and round(random()*5),
  retrying absent index 5 and occupied clips. It preserves all ten original
  placements and their 180-frame sticker timelines. These timelines fade
  their inner panel and stop without clearing outer _visible, so the ten
  slots remain occupied until ResetBonusMetrics. Do not recycle them based
  on opacity. Collision order is car, DMO, body tweak, pedestrian, skater.

## IDA checks for formatting and random choices

- GetLocalizedFormatStringCustom **82622e80** passes a string argument into
  Localizer custom formatting. Read-only histogram/category decoding found
  ID_HOM_SPEED_VALUE=`{0:speed}`, ID_COMMON_METRIC_METERS=`{0:distance}`,
  ID_COMMON_METRIC_TIME=`s`, ID_COMMON_TIME_FORMAT=`hh:mm:ss.ff`.
- ProcessSpeed **8255a3b8**, including instruction inspection, formats with
  zero decimal precision. Original Imperial default converts speed by 2.25
  and uses ID_COMMON_MPH. ProcessDistance **8255a2b8** converts by exactly 3.0
  and uses ID_COMMON_METRIC_NEW_FEET. Existing retained settings are Imperial;
  do not substitute physical conversion factors 2.23694 or 3.28084.
  FormatNumberInternal **82980610** rounds upward when the next decimal is
  at least five (0x82980808), matching the nonnegative metric rounding here.
- GetLocalizedTime **82604280** truncates hundredths and computes hour/minute
  components with the original f32 multipliers/FMA. FormatTime **829812f0**
  delegates to BuildTimeFormatString **82980e30**: omit leading zero minute
  fields, retain authored two-digit seconds/fractions, append localized `s`.
- AptMathObj::sMethod_random **829e9288** and randReloadMersenneTwister
  **829e0680** use a 624-word Mersenne Twister with seed 4357, old 69069 seed
  expansion, and tempering mask 0x9d2c56ff. HoM retains that stream locally;
  exact cross-movie random ordering awaits a shared APT RNG consumer.

No compile or runtime test was run.
The review here consists of original asset decoding, IDA pseudocode and
instruction checks, and source inspection. Runtime visual validation remains
necessary; audio commands are retained for the existing future audio consumer.
