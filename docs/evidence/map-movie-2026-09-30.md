# Original ChallengeMap travel presentation

Source implementation `apps/skate2-pc/src/marker_ui/map_movie.rs`. Confidence:
**high** for the narrow FELocation menu presentation. This is source-reviewed,
not compiled or runtime-tested.
Rustfmt syntax parsing succeeded. No visual-parity claim.

Original external corpus: `data/fe/screens.big` in the January 17 2009 game.
Read-only `tools/extract_big.py` / `tools/inspect_apt.py --scripts` inspection;
extracted assets stayed in the OS temporary directory outside the repository.

The original timeline art, transforms, text, fonts, highlight frames, intro and
outro remain retained APT data. InitAction admission is exact:
`(9,143,59e4), (10,55,1690), (10,54,1fd8), (10,53,1ffc),
(11,25,bd4c)`. Every other nontrivial action is rejected unless explicitly
translated; original two-byte Stop/End uses the existing shared implementation.
No masks are present in the three map/menu movies inspected for masks.

Map constructor `59f0..5b28` sets LIGHT_ON_DARK, disables wrapping and hides
the menu indicator. `67cd` sets **nine** visible rows. Imported menu_picker
`2b00..2bb7` retains a minimum/maximum window with selection;
`3620..3744` attaches ITEMLABEL_DARK with dummy0's height as row spacing.
`3450..357e` updates displayed text; source strings and native count formatting
are supplied by the controller/parent integration. The visible slider is the
original Yellow_Glow skin: SetSliderLength(275), SetNumberOfItems(count,9),
SetValue; its original cap/middle placement and height formulas are translated
from basic_slider `1740..1807`, `18c8..194c`, `1bfc..1cb1`, `1cd4..1f24`.

FELocation native TriggerInfoComponent `8265f180` emits APT state72 then20;
state20 selects challenge_info mode3, **not** property-purchase mode4.
Mission::IsDescriptionEnabled `82625b40` returns false for FELocation substate3;
IsLocationImageEnabled `826256d8` returns false without a Challenge. Therefore
the travel detail component shows its original header and a Teleport menu row,
not a fabricated description/image/objectives/career unlock panel. Positions
follow challenge_info UpdatePositions `3ee4` and `4559`.

Map intro frame1 `6868` enables the screen-manager dimmer; frame34 `6884`
stops and reports IntroComplete, enabling LetterBox information. Outro frame35
`68a4` disables dimmer and LetterBox; frame64 `68d0` reports OutroComplete.
LetterBox uses its original niceintro/niceoutro/infointro/infooutro timelines,
title ID_SCREEN_MAP_TITLE, Marker_streak24 button text and default right
justification (button_menu `8c0..aaa`). The map's Basic bottom menu adds B/Back
then A/Select. LetterBox audio events are recorded for the existing absent
frontend audio backend, not replaced with host sounds.

The native custom map is **not** the placeholder artwork: character68 carries
`_type=MapRenderComponent` (event6f28), and child shape67 has bounds
[-240.5,-240.5,240.5,240.5]. Its original placement inside mcMapPanel is
translation(351.4,306.75), scale0.989593505859375, inside root translation
(469,70) with authored animation changes. Parent integrator owns the native
texture/viewport renderer. ChallengeMap screen template14 is
flat2D, as independently traced by the parent.

Dimmer follow-up: original helper/screenmanager ActivateDimmer `818..854`
guards identical requests, then starts gDimmer intro or outro. The original
screens/main/dimmer is a full 1280x720 **textured** shape, not a guessed black
quad. Its authored alpha frames ramp from07 at frame1 toE5 at frame29 (stop),
then fromDD at frame30 to00 at frame59 (stop/hide). These frames and original
texture remain in asset12, with only actions1348/1370/1390 translated (show,
FE_SOUND_CORE_FADE, hide). The parent draws dimmer_root behind the map. Source
movie metadata says83ms per frame, whereas map and letterbox say16ms; the
existing frontend global tick supplies the timeline update. Imported/loaded
movie timing has not been runtime-validated here.

Remaining scope limits: career challenges, news production, activities, property
purchases and online paths are not reconstructed here. Empty news uses the
authored ID_SCREEN_MAP_NEWS_DEFAULT branch (`6654..6687`) and turns subsequent
news entries off. Native movie references to mcTextNews/mcBacklitStuff/etc that
are absent in the shipped timeline have no AVM target and are not invented.
